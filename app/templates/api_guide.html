Fabio LLM OCR API - Guia de Uso

Bem-vindo à documentação da API do Fabio LLM OCR. Esta API permite analisar currículos usando Reconhecimento Óptico de Caracteres (OCR) e Modelos de Linguagem (LLM).

Visão Geral

Esta API permite dois modos principais de operação:

  • Análise de Requisitos: Avalia currículos com base em requisitos específicos de uma vaga
  • Resumo Automático: Gera um resumo estruturado do currículo com informações principais

Endpoint Principal: /api/analisar

Este endpoint processa arquivos de currículo (PDF ou imagens) e retorna análises ou resumos.

Parâmetros

Nome Tipo Obrigatório Descrição
arquivos File Sim Um ou mais arquivos de currículo (PDF ou imagens)
user_id String Sim ID do usuário que está realizando a análise
query String Não Requisitos da vaga para análise comparativa. Se omitido, gera resumo automático
request_id String Não ID opcional para rastreamento da solicitação

Exemplo: Análise de Currículo com Requisitos

Neste modo, a API avalia o currículo em relação aos requisitos específicos da vaga.

Request

POST /api/analisar

Formato: multipart/form-data

Campos:
- arquivos: curriculo_candidato1.pdf
- user_id: user123
- query: "Desenvolvedor Python com experiência em FastAPI, MongoDB e pelo menos 2 anos de experiência"

Dica: Para melhor desempenho, envie arquivos de boa qualidade. PDFs com texto selecionável funcionam melhor, mas o sistema também pode processar imagens ou PDFs escaneados.

Comportamento do Modelo LLM

A API utiliza modelos de linguagem locais através do Ollama para análise dos currículos:

  • Modelo Primário: llama3.2 - Utilizado para a maioria das análises
Observação: Os resultados podem variar dependendo da qualidade do texto extraído pelo OCR. Em caso de textos muito longos ou se o modelo LLM não estiver disponível, o sistema retornará um erro com código 503. Verifique se o serviço Ollama está ativo e se o modelo necessário está disponível.

Formatos de Arquivo Suportados

O sistema é capaz de processar os seguintes formatos de arquivo:

  • PDF: .pdf
  • Imagens: .png, .jpg, .jpeg, .bmp, .tiff, .tif

O sistema utilizará OCR avançado para extrair texto de arquivos PDF digitalizados ou imagens. Para PDFs com texto nativo, o sistema tenta primeiro extrair o texto diretamente antes de aplicar OCR.

Tratamento de Erros

A API pode retornar os seguintes códigos de erro:

  • 422: Erro de validação - parâmetros inválidos ou faltando (como não fornecer arquivos)
  • 415: Formato de arquivo não suportado
  • 500: Erro interno do servidor
  • 503: Serviço LLM indisponível (por exemplo, modelo não encontrado no Ollama)
